# AI Mental Wellness Support Assistant

## Overview

AI Mental Wellness Support Assistant is a web-based application that helps users reflect on their emotions and receive supportive guidance. The system analyzes user input using Natural Language Processing (NLP), detects emotional patterns, and generates personalized wellness responses using Google's Gemini AI.

## Features

* Sentiment Analysis using TextBlob
* Mood Detection (Stress, Happiness, Sadness, Loneliness, Neutral)
* Personalized AI-generated wellness responses using Gemini API
* Mood-based suggestions and recommendations
* Interactive web interface using Streamlit

## Technologies Used

* Python
* Streamlit
* TextBlob
* Google Gemini API
* Natural Language Processing (NLP)

## Project Workflow

1. User enters their thoughts or feelings.
2. TextBlob performs sentiment analysis.
3. The application detects the user's mood.
4. Gemini AI generates a personalized wellness response.
5. Mood analysis and suggestions are displayed.
